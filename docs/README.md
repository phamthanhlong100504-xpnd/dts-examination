# Tài liệu DTS Examination

Đọc [LOCAL_SETUP](LOCAL_SETUP.md) để cấu hình/chạy repo, [EXAMINATION_FEATURES](EXAMINATION_FEATURES.md) để hiểu luồng nghiệp vụ, [API blueprints](api-blueprint/README.md) để nối frontend và [Migration catalog](db/MIGRATION_CATALOG.md) để hiểu schema.

Các blueprint cũ mô tả nền ban đầu. Index mới chỉ rõ tài liệu hiện hành của phiên bản GPLX, frozen paper, student catalog và result release; khi có khác biệt, dùng contract hiện hành gắn với source. docs/db/SCREEN12_SCHEMA.md được manifest kiểm checksum nên giữ nguyên; hướng dẫn bổ sung đặt riêng để không đổi checksum.
